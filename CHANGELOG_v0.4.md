# Brainrot Education v0.4 changelog

## Identity
- Brainrot Math renamed to Brainrot Education.
- Main title remains “ARE YOU SMARTER THAN A BRAINROT?”
- Legacy save migration added.

## Learning
- Added Math, Time, Calendar, Vocabulary, Reading, Spelling, Grammar, Science, Geography, and General Knowledge.
- All categories adapt to Grades 1–4.
- Added Mixed Brain Battle and parent subject toggles.

## Assessment
- Added Quiz Mode with report card grades.
- Added subject-by-subject quiz score summary.
- Added Professor Brainrot Review for low quiz scores.
- Added explanations, related review questions, mastery tracking, and Focused Retake.

## Presentation
- Added subject labels and skill labels to battles.
- Added analog clock rendering and reading passage cards.
- Added Professor Brainrot academic appearance using glasses, cap, bow tie, vest, and pointer overlays.
- Updated Glorp dialogue from math-only to education-wide jokes.

## Technical
- New generic education question engine.
- New Brainrot Education local-storage key.
- Updated PWA manifest and cache namespace.
- Expanded automated tests to every subject/grade combination.
