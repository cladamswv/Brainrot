# Brainrot Academy v0.11.2 — Kid App Polish

A presentation-only polish pass aimed at making Brainrot Academy feel more like a finished mobile learning game before child testing.

## Presentation changes
- Kid-facing home highlight cards replace development-oriented copy.
- Professor Brainrot now owns the home speech bubble; Glorp is framed visually as the rival.
- Stronger Professor-vs-Glorp battle staging with fighter labels and a desktop VS badge.
- More tactile subject, answer, question, and results cards.
- Compact-phone battle layout keeps the learning question closer to the first screenful.
- Extra support for very narrow phones and short landscape layouts.
- Added 180px Apple touch icon and 32px favicon derivatives.

## Scope
No curriculum, scoring, mastery, or answer logic changed.
