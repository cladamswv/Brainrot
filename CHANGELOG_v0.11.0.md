# Brainrot Academy v0.11.0 — Core Learning Games

## What changed
- Promoted Math, Grammar, Reading, and Spelling into four named featured games: **Number Battle**, **Glorp's Grammar Crimes**, **Reading Detective**, and **Spelling Showdown**.
- Professor Brainrot now owns the question prompt in a speech bubble for all four featured games.
- Glorp stays quiet while the learner thinks, then reacts with his existing voice and animation after the answer.
- Professor gives **CORRECT!** / **WRONG!** visual feedback without requiring Professor voice audio.
- Added a real **Practice Weak Skills** action powered by the existing local mastery engine.
- The home Review shortcut now falls back to mastery practice when there is no unfinished quiz review.
- Added mastery-practice count to parent totals.
- All progress remains local and offline-capable.

## Design intent
The academic decision is now the game event. Professor teaches; Glorp supplies the chaos. The app can grow new game modes without turning learning into an interruption between unrelated rewards.
