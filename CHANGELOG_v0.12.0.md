# Brainrot Academy v0.12.0 — GitHub Android APK Build

## Added
- Capacitor 8 Android wrapper configuration.
- One-command Android debug APK build: `npm run android:build`.
- GitHub Actions workflow that builds an APK on pushes to `main` or manual workflow runs.
- APK artifact upload from GitHub Actions.
- Brainrot Academy Android launcher icon resources.
- Android build documentation and Codespaces instructions that do not require web ports.

## Unchanged
- Curriculum and mastery logic.
- Professor/Glorp learning flow.
- Existing browser/PWA functionality.
