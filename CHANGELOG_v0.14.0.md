# Brainrot Academy v0.14.0 — Premium Visual Foundation

This release begins the studio-quality visual production pass while preserving the v0.13 learning/gameplay architecture.

## Visual foundation
- Added a premium activity-selection environment and scene-backed mode cards.
- Added dedicated Pizza Party kitchen and Milkshake Machine dessert-lab environments.
- Added bespoke vector mode icons for Brain Battle, Pizza Party, and Milkshake Machine.
- Battle staging now changes its environment, HUD tint, question frame, meter icon, and scene signage by gameplay setting.
- Upgraded pizza and milkshake prop rendering, ingredient reveals, lighting, depth, and food-progress presentation.
- Added stronger shared card/button polish, ambient lighting, responsive mode cards, reduced-motion handling, and result-card entrance treatment.

## Product presentation
- Home messaging now reflects multiple gameplay settings instead of presenting the entire app as one Brain Battle.
- Activity selection highlights the core promise: different games powered by the same learning engine.

## Learning safety
- No curriculum, answer validation, mastery scoring, adaptive selection, or parent-progress calculations were changed in this pass.
