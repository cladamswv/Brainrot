# Brainrot Academy v0.11.1 — Presentation Refresh

This update focuses almost entirely on **presentation polish** so Brainrot Academy feels better on phones and more ready for outside testing.

## Highlights
- New app icon set for `192`, `512`, and maskable PWA installs.
- Refined loading screen with cleaner copy and value badges.
- Home screen visual polish with trust-row badges and highlight cards.
- Additional responsive tuning for short phones and landscape orientations.
- Refreshed manifest/theme presentation and build identity updates.

## Notes
- No curriculum logic was changed.
- No Professor or Glorp gameplay flow was changed.
- Existing save data remains compatible.
