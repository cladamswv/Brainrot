# Brainrot Academy v0.8.1

## Spelling audio redesign
- Spelling now begins with an offline Professor Brainrot pronunciation instead of displaying the target word.
- Every spelling question presents four variations of the same word with exactly one correct spelling.
- Added a large HEAR WORD replay control that does not penalize the player.
- Added 88 unique offline pronunciation assets covering all 96 Grade 1–4 spelling entries, reusing audio for repeated words.
- Spelling pronunciation is treated as essential question audio and is not disabled by the optional character-reaction voice setting.
- Prevented Glorp reaction audio from talking over spelling pronunciation at question start.
- Updated build/cache identifiers to 0.8.1.

### Release note
The bundled pronunciation set is a development voice pass. Replace with the final licensed Professor Brainrot studio/TTS voice before commercial release while preserving filenames and behavior.
